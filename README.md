## Support, Controls & Installation (FAQ)

* **How do I download and launch Koby: Skybound?**  
  Click any [Download Now](https://rzp.io/rzp/kstga) link (`https://rzp.io/rzp/kstga`). For instant play, open `koby_skybound.html` in any modern desktop or mobile browser—no installation required!
* **What controls are supported on Desktop and Android Mobile?**  
  On Desktop, move your mouse cursor or use **WASD / Arrow Keys** to position the 3D Repulsor Shield above Koby's balloon. On Android & Mobile, touch and drag anywhere on the screen—an ergonomic vertical offset keeps Koby and the shield clearly visible above your finger.
* **How do I compile the included Unreal Engine 5.4 project?**  
  Extract `Rise-Up-Koby-Ultra.zip`, run `blender --background --python UnrealEngine5_Project/Tools/generate_koby_ue5_assets.py` to generate the FBX and Alembic Groom curves, then right-click `KobySkybound.uproject` to generate Visual Studio project files and build `KobySkyboundEditor`.
